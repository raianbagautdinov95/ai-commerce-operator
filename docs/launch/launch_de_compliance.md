# Запуск на Amazon.de — регистрации для финского продавца (VAT + EPR + др.)

> Памятка под товар: самоочищающийся валик от шерсти, FBA-склад в Германии.
> ⚠️ Это ориентир, не налоговая консультация. Точные шаги по Финляндии лучше
> подтвердить у бухгалтера/налогового консультанта — трансграничные правила нюансные.

## 0. Бизнес (фундамент)
- Нужна **зарегистрированная фирма** в Финляндии: **toiminimi** (ИП) или **Oy** (ООО).
- Финский **ALV/VAT-номер** (FI + Y-tunnus). Без него ничего дальше не делается.
- Время: дни–недели. Стоимость: toiminimi дёшево, Oy дороже (мин. капитал не нужен с 2019).

## 1. EORI-номер (для импорта в ЕС)
- Нужен как «импортёру» для таможни ЕС. Финский EORI = `FI` + Y-tunnus, оформляется в финской таможне (Tulli), бесплатно, быстро.
- При **DDP** товар растамаживает поставщик/форвардер, но EORI всё равно часто требуется. Уточни у форвардера, кто «importer of record».

## 2. Немецкий VAT (ОБЯЗАТЕЛЬНО при FBA в Германии)
- Как только твой товар **физически лежит на складе Amazon в Германии** — возникает немецкая налоговая обязанность → нужен **немецкий VAT-номер** (USt-IdNr).
- Где: немецкий Finanzamt. Для иностранных продавцов проще через **Amazon VAT Services** или сервис (**hellotax / Taxdoo / AVASK**) — они и регистрируют, и подают декларации.
- Время: **4–8 недель** (поэтому запускать СЕЙЧАС). Стоимость: сервисы ~€300–500/год.
- В Amazon Seller Central → Settings → VAT — внести немецкий VAT.

## 3. OSS (One-Stop-Shop) — для продаж в другие страны ЕС
- Если со склада в Германии продаёшь покупателям в других странах ЕС (B2C), при обороте >€10k/год по ЕС применяется местный НДС покупателя.
- **OSS регистрируется в Финляндии** (vero.fi) → одной декларацией платишь НДС по всем странам ЕС. Не нужно регистрироваться в каждой стране (пока хранишь товар только в DE).
- ⚠️ Если потом включишь **Pan-EU FBA** (склады в нескольких странах) → нужен VAT в каждой стране хранения. Для старта: **только DE + OSS**.

## 4. EPR / Упаковка — LUCID (ОБЯЗАТЕЛЬНО)
- **LUCID (Verpackungsregister, ZSVR)**: зарегистрируйся на lucid.verpackungsregister.org → получи **LUCID-номер**.
- Плюс **договор с «дуальной системой»** (лицензирование переработки упаковки): напр. Lizenzero, Reclay, Der Grüne Punkt. Платишь по весу/типу упаковки.
- Внеси **LUCID-номер в Amazon** (Compliance → EPR) — иначе листинг заблокируют.
- Стоимость: регистрация LUCID бесплатна; лицензия упаковки ~€30–200/год (малый объём). Время: дни.
- ⚠️ Если включишь Pan-EU/продажи в FR, IT, ES — у них **свои EPR** (Франция строже всех: упаковка + EPR на товар). Для старта (только DE) — хватит LUCID.

## 5. GPSR (безопасность товара, с 13.12.2024)
- Нужен **«ответственный в ЕС» (Responsible Person)**. Ты как **финская фирма = можешь быть им сам**.
- На листинге/упаковке: имя+адрес+контакт ответственного, идентификация товара, предупреждения/инструкция, базовая инфо о безопасности.
- Запроси у поставщика техдок/декларацию (RoHS у Dimoya уже есть).

## 6. Штрихкоды
- **GS1 EAN** (платно, ~€30–50 за пул) или **GTIN-exemption** у Amazon (бесплатно, если продаёшь без своего бренда — для дженерик-теста подходит).
- На юните — **FNSKU** (Amazon-этикетка): её клеит Dimoya на фабрике (подтвердил).

## 7. Amazon Seller аккаунт
- **Professional**, единый европейский аккаунт (~€39/мес). Верификация бизнеса (документы фирмы, удостоверение, банк).
- Маркетплейс: amazon.de как основной.

---

## Порядок запуска (что за чем)
1. Фирма + финский ALV + EORI (Tulli)  ← если ещё нет
2. Amazon Seller Professional (верификация)
3. **Немецкий VAT** (через сервис) — старт СЕЙЧАС, идёт 4–8 нед
4. **LUCID** + лицензия упаковки → LUCID-номер в Amazon
5. OSS в Финляндии (vero.fi)
6. GPSR: назначить себя Responsible Person, собрать инфо для листинга
7. GTIN-exemption (для дженерик-теста) или EAN
8. К приходу товара: листинг (готов) + фото с образца → запуск

## Ориентир по бюджету (разовое + 1-й год)
- Немецкий VAT-сервис: ~€300–500/год
- LUCID + лицензия упаковки: ~€50–150/год
- EAN (если не exemption): ~€40
- Amazon Pro: €39/мес
Итого укладывается в заложенные ~€150–300 «на регистрации» из плана €2500.
